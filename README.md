# React + Vite

This template provides a minimal setup to get React working in Vite with HMR and some ESLint rules.

Currently, two official plugins are available:

- [@vitejs/plugin-react](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react) uses [Oxc](https://oxc.rs)
- [@vitejs/plugin-react-swc](https://github.com/vitejs/vite-plugin-react/blob/main/packages/plugin-react-swc) uses [SWC](https://swc.rs/)

## React Compiler

The React Compiler is not enabled on this template because of its impact on dev & build performances. To add it, see [this documentation](https://react.dev/learn/react-compiler/installation).

## Expanding the ESLint configuration

If you are developing a production application, we recommend using TypeScript with type-aware lint rules enabled. Check out the [TS template](https://github.com/vitejs/vite/tree/main/packages/create-vite/template-react-ts) for information on how to integrate TypeScript and [`typescript-eslint`](https://typescript-eslint.io) in your project.


# Altrium Pulse

Altrium Pulse is a web-based employee performance tracking and development system designed to help organizations manage employee goals, performance reviews, feedback, and professional development in one centralized platform.

## User Roles

Altrium Pulse supports four main user roles:

- Employee – Track goals, progress, reviews, feedback, and development.
- Immediate Supervisor – Manage team goals, reviews, feedback, and employee progress.
- HR Business Partner (HRBP) – Manage performance processes, review cycles, and employee development.
- Leadership (Management) – Monitor performance and organizational development at a broader level.

## Features

- User login and authentication
- Role-based dashboards
- Employee profiles
- Goal creation and assignment
- Goal progress tracking
- Self-assessment
- Peer reviews
- Performance feedback
- Review cycle management
- PAR (Performance and Review) meetings
- Evidence submission
- Team and member management

## Technology Stack

- React
- Vite
- JavaScript
- CSS
- Supabase
- Vercel
